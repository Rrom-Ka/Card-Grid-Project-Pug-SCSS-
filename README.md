# Card Grid Project (Pug & SCSS)

Учебный проект по созданию адаптивной сетки карточек товаров с использованием современных инструментов фронтенд-разработки.

---

## 🛠 Технологии и инструменты
*   **Pug (Jade)** — использование циклов (`each`) и массивов объектов для динамической генерации HTML.
*   **SCSS** — использование переменных, миксинов (`@mixin`) и вложенности (Nesting).
*   **BEM (БЭМ)** — строгая методология именования классов для чистоты кода.
*   **VS Code Settings** — настроенная автоматическая компиляция стилей.

## ⚙️ Конфигурация Live Sass Compiler
Проект содержит файл настроек `.vscode/settings.json`, который автоматически:
1. Компилирует чистый CSS в папку `/css`.
2. Создает минифицированную версию в `/dist/css`.
3. Добавляет вендорные префиксы для поддержки последних 2 версий браузеров.
4. Генерирует `Source Maps` для удобной отладки.

## 📂 Особенности реализации
*   **Миксин `makeContainer`**: универсальный инструмент для центрирования контента с адаптивными отступами.
*   **Цикл Pug**: карточки товаров рендерятся из массива данных, что позволяет масштабировать проект за секунды.
*   **Цветовые переменные**: легкое изменение темы оформления через одну переменную `$colorBackground`.

## 🚀 Как запустить локально
1. Установите расширение **Live Sass Compiler** в VS Code.
2. Склонируйте репозиторий.
3. Нажмите кнопку **Watch Sass** в нижней панели VS Code.
4. Откройте `index.html` через Live Server.
